# Security Policy

## Supported Versions

| Version | Supported |
|---------|------------|
| 0.1.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

**Please do NOT**:
- Open a public issue
- Discuss it in public forums
- Exploit the vulnerability

**Please DO**:
- Send an email to the maintainer
- Include details about the vulnerability
- Include steps to reproduce
- Allow time for the issue to be addressed before disclosure

## Response Timeline

- Initial response within 48 hours
- Estimated fix timeline communicated within 1 week
- Security advisory published when fix is released

## Security Best Practices

This project follows these security practices:

- Minimal dependencies (only click and rich)
- No external network calls
- Local-only data access
- No handling of secrets or credentials
- Regular dependency updates

## Dependency Management

We use Dependabot to automatically monitor and update dependencies. Security updates will be reviewed and merged promptly.
